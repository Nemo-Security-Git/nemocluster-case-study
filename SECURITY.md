# Security Policy

## Reporting a Security Concern

Do not disclose suspected vulnerabilities, internal addresses, hostnames, device identifiers, credentials, configuration fragments, customer information, operational screenshots, access instructions, recovery procedures, or exploit paths in a public issue.

Use GitHub’s private vulnerability-reporting or private security-advisory channel for this repository when available. Include only the minimum information necessary to describe the concern safely. The maintainer may request further details through a private channel.

## Scope

This repository contains a sanitized architectural case study and no production infrastructure code. Reports concerning public documentation, accidental disclosure, repository configuration, or published assets are in scope. Requests for network access, topology, operating procedures, credentials, deployment guidance, or recovery commands are out of scope and will not be provided.
